# TODO清单
> 用于记录开发过程中的待办事项

## 锁定工程类型和重点章节（3.5.1）

- 把这些决定写进 ADR，例如 `0002-锁定市政道路工程.md`
- ADR 的格式见附录 B，内容写清楚"选了哪个、为什么选它、放弃了哪些、有什么影响"

## 准备业务样本（3.5.2）

- 在 `evaluation/manifests/` 目录下创建一个清单文件
- 记录每份样本的编号、类型、工程类型、授权状态、脱敏方式、文件哈希值，以及它属于调试集还是保留集
- 清单的格式可以用 Markdown 表格，也可以用 JSON，重要的是信息齐全

## 补齐架构决策记录（3.5.3）

- 每条 ADR 半页到一页，包含背景、决策、备选方案、后果四个部分
- 附录 B 有模板
